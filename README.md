# Домашнее задание #3
## Анализ C/C++ вакансий с использованием RustFS, MapReduce и DuckDB

## Описание
Проект представляет собой аналитический пайплайн для обработки данных о C/C++ вакансиях. 
Данные хранятся в объектном хранилище RustFS (S3-совместимое). 
Анализ выполняется двумя способами: собственной реализацией MapReduce (чтение чанками) и SQL-запросами через DuckDB.

Примечание: перед запуском необходимо указать ACCESS_KEY и SECRET_KEY в файле config.py (по аналогии с ДЗ №2 использовались myaccesskey / mysecretkey для поднятия RustFS)

## Стек
- **Хранилище:** RustFS (Docker)
- **Обработка:** Python (boto3, multiprocessing), DuckDB
- **Данные:** Датасет IT-вакансий (сегмент C/C++)
